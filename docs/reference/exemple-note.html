Les boucles

Java et Python côte à côte

1. Pourquoi une boucle ?

Une boucle répète un bloc d'instructions tant qu'une condition reste vraie. On écrit i < n pour « i strictement inférieur à n ».

Définition Une itération est un passage dans le corps de la boucle.
Étape 1 : initialiser Base On fixe la valeur de départ du compteur.
🧠 Analogie du quotidien

Faire des tours de piste : on recommence tant que le chrono n'est pas écoulé.

⚠️ Petit piège de réflexion

Oublier d'incrémenter le compteur donne une boucle infinie.

2. Syntaxe

JAVA 
for (int i = 0; i < 3; i++) {
    System.out.println("tour " + i); // affiche 0, 1, 2
}
PYTHON 
for i in range(3):
    print("tour", i)  # affiche 0, 1, 2

3. Quiz

Question 1 (QCM) — Combien de tours fait range(3) ?

A) 2
B) 3
C) 4
D) Infini

Voir la correction

Réponse : B. range(3) produit 0, 1 et 2.

Question 2 (Vrai/Faux) — « Une boucle while s'exécute toujours au moins une fois »
Voir la correction

Faux. C'est le do / while qui garantit un premier tour.
